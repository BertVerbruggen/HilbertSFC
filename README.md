Hilbert SFC codebase, analysis and data for reproduction of results as presented in our paper.
Data is split in Transformer models, Deep CNN's and source code.
Used datasets: 
Imagenette, CIFAR10
Off-the_shelf models:
ViT, ResNet, VGG
Verbruggen, B., & Ginis, V. (2023). Improving image classification of one-dimensional convolutional neural networks using Hilbert space-filling curves. Applied Intelligence, 53(22), 26655-26671.
Link to paper:
https://link.springer.com/article/10.1007/s10489-023-04945-2
